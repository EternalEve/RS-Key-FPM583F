# 外壳整体重审与 V12 候选方案

2026-11-02，Asia/Shanghai。目标由用户确认为：缩小体积，同时保证承力和装配可靠。
本次保留现有 PCB 叠层、接线、USB 插头和 FPM583F，不更换硬件布局。

本页保留 V12 的历史重审记录。当前生成器和检查入口已更新为 [V13 槽底圆角](concept-v13.md)；
复现本页的 V12 需使用 `build/v12-source-preserved.zip` 中的源文件，原 V12 加工包仍保留。

## 判断

**现有证据不能支持 V11 是最优解。** 它解决了前壁下端自由的问题，但为保留上盖一体前壁，
又在两侧叠加插脚、插槽、挡肩和托架避让，使最大宽度从 V9 的 27.2 mm 增至 33.6 mm。
这是既有分件方式下的取舍，不是 18 mm 宽 PCB 或 21 mm 指纹模块强制要求的宽度。

建议把下一轮试验转向 **V12：深底壳直接承力、浅上盖压紧、左右可拆托架**。
已另建 51.8 × 28 × 19 mm 候选 CAD；V11 的源文件、STL 和加工包不替换。
V12 是用于结构比较的候选稿，不能据此宣称承载能力优于 V11 或已经可以量产。

## V11 的主要问题

| 项目 | 证据 | 工程含义 |
| --- | --- | --- |
| 分件方式使前端膨胀 | `concept-v10.md` 的两组插脚中心 Y = ±13.5 mm；`trial_model.py` 的前宽 33.6 mm | PCB 两侧依次放托架、插脚、槽壁和外壳，横向占位累加 |
| 抗拔支路先经过配合间隙 | 插脚向外目标间隙 0.1 mm；0.08 mm 不接触、0.15 mm 接触 | 下端支路不是初始固支，受载分担、接触冲击及磨损均未知 |
| 需要多处精细修配 | 定位柱 4.8 mm 配 4.9 mm 孔，加上 T 形槽的间隙 | 多处尺寸同时影响装配；不能把 CAD 间隙当成打印保证 |
| 上盖承担多种职责 | 前止挡、前壁筋、T 形脚、螺柱、指纹上压及检修孔均在上盖 | 局部改动容易牵连板件净空、闭合路径和前壁约束 |
| 缺少决定“可靠”的载荷条件 | `concept-v11.md` 明确尚无实物拔出力、破坏载荷和疲劳验证 | 增加筋厚或保留材料体积不能证明整机更耐用 |

这些是设计审查结论和未关闭的验证项，不是已复现的实物断裂故障。
指纹台阶承托、金属隔离、独立线束空间以及不借用 PCB 电气孔固定的原则仍值得保留。

## 方案比较

| 方案 | 尺寸潜力 | 装配与承力代价 | 本轮选择 |
| --- | --- | --- | --- |
| 沿用 V11，继续缩小 T 形脚 | 可局部缩窄，极限尚未检查 | 精细配合和有间隙的抗拔支路仍在，可能牺牲槽壁或托架截面 | 作为对照，不继续叠加补丁 |
| 深底壳＋浅盖＋可拆托架 | 已建 28 mm 宽候选，保留 19 mm 高度 | 固定前止挡与底壳连为一体；仍有四件、托架定位及薄壁验证 | **均衡方案，优先试验** |
| 两件式底壳，承托全部一体化 | 件数可减少 | 固定托片可能挡住下层 PCB 或排针的下落路径；现有数据不能排除 | 暂缓，须先补齐下层几何 |
| 左右对开壳体 | 可能减少上下方向的装入限制 | 接缝贯穿 USB 和指纹周围，横向螺丝及绝缘布局需重做；未建模 | 保留为后备方向，不声称不可行 |
| 外套筒＋独立端框或滑入托盘 | 可把止挡与外观壳分开设计 | 增加端部锁定、滑动配合和线束装入问题；未验证的尺寸潜力 | 本轮不优先 |
| 重新设计单层 PCB | 有进一步降低厚度的空间 | 改变已经使用的硬件和接线，范围显著扩大 | 超出本轮边界 |

没有给各方案编造强度评分或“最优概率”。未完成建模的方案只比较结构取舍。

## V12 怎样重新分配职责

拔出时的主要路径改为：

```text
PCB 前沿 → 底壳一体前止挡 → 底壳前角、侧壁及底板 → 手持壳体
```

V11 的对应路径是 PCB 前沿先推上盖薄前壁，再由上端筋、顶板和螺柱传力；
下端 T 形脚消除间隙后还可经挡肩传力。V12 取消这组插脚及插槽，
让前止挡的连接不再依赖其接触间隙。**这只简化了连接关系，并未证明薄壁应力更低。**

插入时仍由尾部硬止挡、托架安装耳及定位柱把反向载荷传到底壳。
上盖螺柱仍夹持安装耳；前端上方小筋限制 PCB 抬起，指纹上唇通过硅胶压台阶。
若用户握上盖拔出，载荷仍须跨越合壳连接；不能据此降低螺丝、嵌件和上盖的要求。

| 部位 | V12 名义设计 |
| --- | --- |
| 外形 | 长 51.8、最大宽 28、高 19 mm，不含外露 USB；尾部仍宽 26 mm |
| 前段与主体 | 主体宽 28 mm 延伸至螺柱区域，随后过渡到圆形尾部；前角 R1.4 |
| 分件 | 深底壳、浅上盖、左托架、右托架，仍为四个塑料件 |
| 前止挡 | 改属底壳，前端 X = 0，PCB 前边 X = 0.8；USB 槽朝上开口 |
| USB 上沿 | 上盖上的短桥补齐上沿，两侧各留 0.2 mm；无需让闭孔穿过插头 |
| 合壳接缝 | 底壳顶 Z = 17.3、上盖底面 Z = 17.4；名义 0.1 mm，安装耳处优先夹紧 |
| 上盖定位 | 两条浅导向筋，名义间隙 0.3 mm；承担装配导向，不作为精密 PCB 轴向止挡 |
| 托架 | 延用 V11 的板件接触面及补强构造，在新轮廓内重新生成；不保证与 V11 实物互换 |
| 螺丝与嵌件 | 保留两颗 M2 × 10 及 M2、OD3.6 × L4 嵌件，螺丝从底部装入 |
| 指纹承托 | 保留一体下托环、台阶受力及原硅胶规格；上盖压环让位处尾壁名义约 1.4 mm |
| 螺柱圆角 | 上盖螺柱根部补料限制在底壳内腔范围；不向深底壳侧壁穿透 |

28 mm 的横向预算可从托架复核：前支柱外缘为 Y = ±12.2 mm，
加每侧 0.2 mm 空隙和 1.6 mm 主体壳壁，合计 `2 × (12.2 + 0.2 + 1.6) = 28 mm`。
前部内让位半宽 12.4 mm；R1.4 前角留下 12.6 mm 半宽直边，容纳该让位区。
这是本候选的几何预算，不是所有拓扑或工艺下的最小宽度证明。

最大宽度减少 **5.6 mm / 16.7%**；长度、高度不变。
同尺度的实际俯视轮廓面积约由 **1430.1 降至 1341.1 mm²，减少 6.2%**。
16.7% 不能写成实际整体体积或用料减少比例；详细结果见 `build/v12-comparison.json`。

四件塑料网格的实体体积约由 9619.7 降至 8919.0 mm³，减少 7.3%；
不含硅胶和金属，也未计入商家排版、清粉及后处理费用，不据此承诺加工价格。

另外两个方向也审查了，但没有仅为减小数字而收紧：

- **高度**：14 mm 叠层上限、上下各 1.6 mm 壳壁及合计 1.8 mm 净空构成当前 19 mm 预算。
  进一步减薄应先确认实际针脚、焊锡和最高器件，而不是直接压缩这部分净空。
- **长度**：PCB 尾边为 X = 24.3，指纹中心 X = 38.8，21 mm 台阶前缘 X = 28.3。
  中间还布置尾部托架、两颗嵌件和配对插头。按现有嵌件与模块腔体的隔离公式，
  保持螺柱原位时，指纹中心前移的名义余量仅约 0.66 mm；明显缩短需要一起重排螺柱与线束。
  当前没有配对插头及回弯线束的完整实测包络，因此保留 51.8 mm，而不宣称长度已经最优。

## 装配顺序

1. 两半托架仍从左右水平套住板件裸边，装好三片 PCB 硅胶垫。
2. 板件、USB 插头和托架一起从上方落入深底壳。USB 经过向上敞开的前槽；托架随板件运动。
3. 安装指纹模块及环形垫，在线束通道内理线，不以合盖挤压线束。
4. 竖直放下浅上盖，短桥补齐 USB 孔上沿，上盖螺柱夹住托架安装耳。
5. 从底部装入原规格两颗螺丝，检查安装耳实际夹紧、周边接缝及绝缘。

深底壳会使取件及清理比浅底壳困难，应在试装时评价工具可达性和排粉。
不增加弹性卡扣、胶粘固定或 PCB 上的金属安装件。

## 检查方法与边界

运行环境、导出方法和参考模型沿用现有项目。新入口为：

```sh
nix develop -c python enclosure-design/verify_redesign.py --openscad "$OPENSCAD"
nix develop -c python enclosure-design/redesign_preview.py
HOST_TARGET=x86_64-unknown-linux-gnu nix develop -c ./scripts/check.sh > enclosure-design/build/v12-project-check.log 2>&1
```

`verify_redesign.py` 独立检查四件闭合实体、六组配合、18 × 23.5 mm 名义 PCB、
官方器件包围盒、14 mm 叠层占位、USB、硅胶、1.2 mm 金属预留和线束通道。
以连续扫掠检查板件与托架整体下落、浅盖闭合；侧向套托架检查七个离散位置。
连续扫掠只覆盖所建刚体、名义位置及规定的竖直路径，不包括电线柔性运动。

检查分别要求：前止挡无需上盖也能阻挡 PCB 前移；移除前止挡后该接触消失；
尾部止挡、定位柱、安装耳及上盖螺柱能阻挡对应的越界位移。
对 PCB、USB、指纹和金属另做故意偏移，确认相应碰撞检查能够检出干涉。
打印零件要求单一闭合实体；检查用相交网格可带零厚度接触面，其正体积用于判断碰撞。

首次候选运行在上盖螺柱圆角与底壳侧壁、指纹压环与尾部内壁处检出干涉；
前者改为内腔裁切补料，后者增加局部让位，随后重跑。首轮记录保存于
`build/v12-first-pass-failures.json`，最终结果以 `build/v12-geometry-checks.json` 为准。

前止挡检查还须通过正式入口的缺失对照：

```sh
nix develop -c python enclosure-design/verify_redesign.py --openscad "$OPENSCAD" --without-front-stop
```

| 运行 | 应出现的结果 | 判读 |
| --- | --- | --- |
| 正常候选 | `base-stop-blocks-forward-0.10mm` 有正碰撞体积 | 底壳确有前止挡 |
| 检查内部移除前止挡 | `removed-base-stop-no-longer-blocks` 无正体积 | 接触来自目标止挡 |
| 正式入口 `--without-front-stop` | 首项失败、第二项仍通过，进程退出 1 | 没有把“放行”误认为拦截，也不是导出或断言错误导致失败 |

这个入口是机械候选的专用检查，尚未接入项目 CI；`check.sh` 通过不替代该入口。
网格结果也不替代强度、材料性能或公差分析。

## 进入打样前仍需关闭的问题

- **轴向公差链**：0.8 mm 名义阻挡仅剩 0.2 mm 总预算。定位孔仍为单边 0.05 mm 的修配目标，
  深底壳并未自动消除打印误差、PCB 尺寸差和板件偏斜。
- **薄壁承载**：0.8 mm 前壁仍承受 PCB 前沿作用力；必须比较 V11/V12 的局部弯曲、裂纹、
  PCB 位移及螺丝连接载荷。不能只按“连接更直接”给出额定拔力。
- **板边接触**：前沿 1.05 mm 下托区、上方小筋及尾端裸边仍须核对实物焊锡与器件。
  官方 STEP 未包含完整 Flash、USB、下层 PCB、排针和线束。
- **制造与绝缘**：确认前薄壁、尾部局部 1.4 mm 壁、孔修配、嵌件装入、排粉和去毛刺；
  商家给出的最小可打印特征不能直接当成承载厚度或定位公差保证。
- **接口使用空间**：最大宽度变小不证明相邻接口不被挡住，也不证明能穿过电脑凹口；
  仍须按实际主机外形检查插入到底、手指触摸和按钮操作。

HP 的 [MJF Handbook](https://reinvent.hp.com/us-en-3dprint-mjfhandbook)
分别列出薄壁、尺寸公差、配合、嵌件及机械性能章节；
[HP 与 Protolabs 的手册](https://www.protolabs.com/media/sq1l5it2/hp_mjf_handbook.pdf)
也将尺寸变化和配合放在装配设计早期考虑。这里据此把“可打印”“可装配”和“承载通过”分开判定，
不将材料典型值或通用最小壁厚视为本壳的实测能力。

下一步应对 V11 与 V12 使用同批材料、同方向打印，先做断电配合与绝缘检查，
再依据实际接口拔出力确定试验载荷、偏心力矩及循环目标。
记录两版在相同载荷下的前壁位移、板件位移和失效位置，才能判断均衡目标下是否应替换 V11。
本轮未操作硬件、未进行通电验证或力学仿真。
