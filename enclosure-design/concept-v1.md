# 外壳结构初稿 V1

状态：布局讨论稿。尺寸、固定接触面和金属隔离间距尚未由实物验证，不用于加工下单。

后续用户将板件总厚度上限修正为约 14 mm，按当前壁厚与净空预算壳高为 19 mm。
保留作外形历史对照，当前预算见 [V3](concept-v3.md)。

## 外形与布局

采用 USB-C 前端略收窄、尾部圆润加宽的长条外形，感应面朝上。
两块 PCB 保持现有叠放关系，指纹模块沿长度方向放在后方；不为缩小外壳改接线。
内部按 PCB、线束过渡、指纹模块三个区域布置。

初稿壳体包络约为 64 × 34 × 18 mm，不含伸出的 USB 插头。
这是用于讨论的设计假设，不是照片测量结果；尺寸将随实际板厚和线束空间调整。

## 拆装与固定

采用底壳、上盖和后续独立设计的模块压环，不使用卡扣。
初稿考虑四个壳体螺丝位置：PCB 两侧各一个、指纹模块两侧各一个。
四点分布便于同时约束前后两个区域；位置和数量以实测避让结果为准。

底壳负责定位和承托，上盖负责封闭；不能用拧紧上盖来挤压 PCB 或模块。
定位止口、PCB 压条和指纹压环须在安装接触面确认后设计，当前包络模型没有定稿这些结构。
拆开上盖时，PCB、指纹模块和线束应能够留在底壳，不被上盖牵拉。

## 螺丝与电路隔离

螺柱在 PCB 电气包络外，朝电路的一侧设置连续塑料隔壁。
模型展示底部螺丝通道和上盖嵌件盲孔；盲孔上方保留塑料封顶。
PCB 不使用已有焊孔安装，固定位置不能压住焊点、元件或排针。

金属件边界须包含螺丝头、垫圈（如有）、螺纹嵌件和最长允许螺丝尖端。
将商家加工公差、嵌件安装偏差、PCB 偏移及底部焊脚一并纳入间距核对。
模型里的螺柱外形不等于已证明绝缘，最终须按实际金属件和电路几何检查。

首次试装在断电状态下进行，检查穿透、夹线、松动金属件和电路受力。
确认安装后再安排通电、普通触摸、长按释放及真实指纹匹配回归。

## 指纹区

本地模块手册 V1.0.2 第 9 页的结构图标出最大外径 21 ± 0.1 mm、
另有 19 ± 0.1 mm 和 17 mm 的直径尺寸，以及 6.3 mm 的侧向总包络尺寸。
这些尺寸来自手册，不代表照片中的实物已经量过。

初稿仅用圆柱包络表示模块，并留全外径开口和下方承托示意。
背部插头、定位凸起、台阶方向和线缆出线须另行测量。
在确认可承力台阶前，不定稿压环，也不以夹紧感应面或透光圈固定模块。
目前上盖开口不提供向上防脱，模型不能作为完整装配使用。

## 材料与外观方向

建议普通未增强 PA12 尼龙、MJF 工艺、染黑哑光，交由商家核对材料和嵌件工艺。
感应面和需要透光的原有外圈保留外露，壳体周围使用圆滑过渡。
外观以平整上表面和圆角为主；BOOT、RUN 和 LED 的孔位目前均为占位。

## 当前模型与生成

`model.py` 是参数化包络模型源文件，只使用 Python 标准库生成 OpenSCAD 源码。
生成的 CAD 源码和预览位于本目录忽略的 `build/`，不是加工交付物。

```sh
nix develop -c python enclosure-design/model.py --variant v1
```

使用 OpenSCAD 打开 `build/concept-v1.scad` 查看。默认显示分解布局；
`part` 可选 `assembled`、`exploded`、`base`、`lid` 或 `section`。
模型参数集中在 Python 源文件开头，均附带来源类别；不得将占位参数当成实测值。

模型目前不包括定稿的压环、PCB 压条、按钮机构、定位止口和完整线束约束。
这些都依赖实际接触面与尺寸，不能据当前模型宣称装配或防短路已经验证。

在已提供 OpenSCAD 与 librsvg 的开发环境中，可重新生成讨论预览：

```sh
nix develop -c openscad -D 'part="assembled"' -o enclosure-design/build/assembled-check.off enclosure-design/build/concept-v1.scad
nix develop -c openscad -D 'part="exploded"' -o enclosure-design/build/exploded-check.off enclosure-design/build/concept-v1.scad
nix develop -c python enclosure-design/preview.py
nix develop -c rsvg-convert -o enclosure-design/build/concept-v1-preview.png enclosure-design/build/concept-v1-preview.svg
```

项目默认开发环境不包含 OpenSCAD 和 librsvg，须另行提供，不修改固件依赖。
当前已通过模型脚本语法、SPDX、底壳及上盖实体几何检查；没有运行完整软件门禁。
几何检查只证明这两件是可计算的连续实体，不证明配合、装配或金属隔离成立。

## 下一步需要的实测数据

| 数据 | 测量范围 | 用途 |
| --- | --- | --- |
| PCB 长宽 | 两块分别测，包含超出板边的器件 | 确定定位腔及螺柱避让 |
| 叠层总高 | 最低焊脚到最高器件，不挤压板间连接 | 确定壳高、底部净空和压条位置 |
| 模块尺寸 | 最大外径、厚度、台阶及定位凸起 | 定稿承托、压环与正面开口 |
| 插头和线束 | 两端连接器高度、出线方向及自然弯曲空间 | 定稿过线槽和模块间距 |
| USB 与按钮 | 插头中心高度、伸出长度、BOOT/RUN/LED 坐标 | 定稿接口和操作孔 |

先核对尺寸和固定面，再出配合小样，试装通过后导出完整加工文件。
