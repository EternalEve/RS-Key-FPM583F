# V9 保留筋芯截面的圆角试装壳

状态：修正 V8 为圆角抬高筋根、局部损失承力截面的问题，尚未完成实物配合、拔出力、绝缘或寿命验证。
采用全塑料结构，普通未增强 PA12、MJF、染黑哑光；不新增金属前框或 PCB 安装孔。
名义外形 **51.8 × 27.2 × 19 mm**，不含外露 USB；前端较 V7 加宽 1.2 mm，尾部仍宽 26 mm。
四个打印件、两颗 M2 × 10 螺丝及四片硅胶垫。

## 怎样改善前端承力

用户转述的仿真指出 V8 小筋连接前壁的下端存在截面损失；本次源码和几何复核确认了该损失。
未取得该仿真的材料卡、接触、约束、载荷及网格收敛记录，未独立复核其变形或载荷数值。
本版恢复 V7 的筋芯高度和下缘截面，在此基础上补圆角；不以抬高筋根换取圆角空间。
V8 的外侧筋横向位置、前端加宽、托架和配套避让继续保留。

沿用 **0.8 mm 上盖一体前壁**及四道后向加强筋：

| 结构 | 位置和名义尺寸 |
| --- | --- |
| 两道外侧筋 | 芯部 Y = ±10.2～±11.8 mm，宽 1.6 mm；向后 6 mm；剖面起点恢复为 Z = 12.1 mm，向后升至顶板；超出外轮廓的部分裁齐 |
| 两道板边上方筋 | 中心 Y = ±5.4 mm，芯宽 1 mm；向后 4 mm；前壁侧起点恢复为 Z = 13.7 mm，低位平段向后 1.2 mm，随后升至顶板 |
| 前壁 | X = 0～0.8 mm；下缘 Z = 1.7 mm，顶端与上盖相连 |

拔出时，PCB 相对壳体趋向 USB 前端移动，前沿抵住绝缘前壁。
力由前壁、加强筋传到上盖顶板和侧壁，再经螺柱及两颗合壳螺丝传到整壳。
0.8 mm 前壁仍然承力，不能据此认为它不再受弯。
圆角处理显式保留原始筋芯多边形，再并入圆角补料，避免圆弧替代筋芯而削弱局部截面。
这不构成不会撕裂、破坏拉力或疲劳寿命的证明；保留截面也不能证明整体刚度或抗裂优于 V7。

| 主要过渡 | 名义半径与处理 |
| --- | --- |
| 外侧大筋与前壁、顶板 | R0.8；包含剖面内凹角及筋两侧的根部过渡 |
| 板边上方小筋与前壁、顶板 | 侧面和接顶板处 R0.4；保留 Z = 13.7 mm 的原始筋根及板面限位 |
| 前壁转入顶板 | R0.6，连续补料；原顶板下前端台阶让空后接入圆角 |
| 上盖螺柱转入顶板、底壳螺柱转入底板 | R0.8，环形根部补料，按壳体外轮廓裁齐 |
| 上盖侧壁转入顶板、底壳侧壁转入底板 | R0.6，曲线截面沿周边过渡 |
| 前下托片转入支撑柱 | 内侧根部 R0.6、前侧根部 R0.4；上接触面保持平面 |
| 托架侧梁转入安装耳 | R0.6；底壳局部让出相应圆角及 0.2 mm 名义间隙 |
| 底壳中央薄前壁转入底板 | R0.6，向内补料 |

圆弧以有限分段导出，环形与局部根部采用 64 段整圆，壳周边截面采用 16 段四分之一圆。
小筋靠板的下缘受 0.2 mm 净空限制，保留平直边界，不能向下补满 R0.4；侧面及顶板圆角不等于下缘所有方向都已倒圆。
PCB 止挡、托面、嵌件孔和装配配合面保留功能所需的平直形状，未对所有外观边统一倒圆。

所有补料均限制在既有外轮廓或壳内，不增加向 USB 插入方向的突出量。
大筋沿用 V8 向两侧各外移 0.6 mm 的位置，起点从 V8 的 Z = 13.0 恢复至 V7 的 12.1 mm；前托柱也沿用外移后的空间。
前托柱前缘改为 PCB 前边之后 0.6 mm，避让槽最前端不越过 PCB 前边。
前端加宽后，避让槽外缘仍落在前端直边范围，前部保留至少 0.8 mm 名义壁厚，不以削薄前角换空间。
小筋前壁侧起点从 V8 的 Z = 15.2 恢复至 13.7 mm；板面上方平段向后到 1.2 mm 深度，最低处仍保留 0.2 mm 名义间隙。
这些局部空间用官方器件包围盒单独核对，不能当作整块板上的通用净空。
实物 USB 根部、手工焊锡及该区域是否另有附加件仍须检查。

前壁的 USB 孔向下开口，底壳中央增加宽 8.8 mm、厚 0.8 mm 的前壁，顶面 Z = 13.25 mm，合壳后补齐 USB 下沿。
两侧接缝名义各留 0.2 mm。这样上盖可从上方绕过已焊好的插头，而非让封闭孔下沿穿过插头。
拔出方向主要依靠上盖两侧前壁与加强筋传力；中央下沿是底壳前壁的一部分，仍须与整壳一起验收变形及裂纹。

## USB 阻挡与尺寸余量

PCB 前边 X = 0.8 mm，所有壳体最前端 X = 0，名义轴向阻挡 **0.8 mm**，按用户报告的 8 mm 伸出量计算，名义外露 7.2 mm。
预留 **0.2 mm** 合计余量，暂分配给内部位移 0.1 mm、加工及装配误差 0.1 mm。
该预算不是商家精度保证或完整公差链证明；不能把前壁自行加厚至 1 mm 后仍沿用此预算。

所有前部表面的实际阻挡必须 **≤ 1.0 mm**，包括前壁、边角、底壳及打印变形。
商家须确认 0.8 mm 壁和细筋的加工能力；最终以尺寸测量及实际插入到底为准。
USB 孔仍为 9.2 × 3.5 mm、R0.4、中心 Z = 15 mm；实际焊接偏斜和根部宽度尚未独立测量。

## 左右内托架与装配方向

前后承托合并后，沿 Y = 0 分成左右两件，中央名义间隙 0.2 mm。
每件包含前下托片、外侧梁、尾端支架及一只安装耳；从板件左右两侧水平套入，再将整组竖直放入底壳。
这样保留双层 PCB 的装入通道，不要求把带排针的板件从完整框架中穿过。

前下托片沿 X 伸入 1.05 mm，承托从 Y = ±4.9 mm 延伸至板外侧，底面 Z = 10.9、顶面 Z = 11.9 mm。
支撑柱位于 Y = ±10.2～±11.4 mm，向外让出根部圆角；上下壳均作相应避让。
前托柱避让槽向内覆盖 R0.6 根部及 0.2 mm 名义间隙，避免圆角顶住原槽边。
前沿 1.05 mm 的下托面及上方 1.2 mm 内的短平托面须实物确认没有焊锡、器件或排针外伸。

尾端仍从未焊排针的裸板边承托，伸入 0.4 mm；上压条底面 Z = 13.7 mm。
两片尾垫向前预压 PCB，一条上垫向下预压；硬止挡离名义尾边 0.05 mm。
硅胶只负责预压及消隙，拔出方向的固定不以摩擦力为依据。

安装耳成为单件厚 2.5 mm，Z = 7～9.5 mm；底壳肩面承托，上盖螺柱夹紧。
尾托底脚槽沿底脚轮廓均匀外扩 0.2 mm，并向上覆盖底部螺柱圆角高度，防止新增根部与底脚相撞。
底壳绝缘定位柱直径 4.8 mm、托架孔 4.9 mm，顶面 Z = 9.3 mm。
单边 0.05 mm 为最终配合目标，须试孔和修配，不能视为 MJF 原始打印精度。
上盖周边仍留 0.1 mm 名义高度间隙，防止先由周边顶死而使安装耳悬空；实物须确认夹紧接触。

## 沿用的模块、垫片与金属件

板件总厚度上限约 14 mm，主板面至最低针脚约 11 mm，主板面 Z = 13.5、最低针脚 Z = 2.5 mm。
数据仍来自用户报告，未独立复测。指纹模块及板件基准相对 V6 向后 0.1 mm，其他高度预算不变。

指纹下托环仍与底壳一体，内径 19.4、外径 22.2 mm、顶面 Z = 15.9 mm。
模块 21 mm 台阶承力，上方硅胶环预压台阶；不以检测面作为压紧面。
指纹主体 19 mm、台阶 21 mm、面至台阶 2.1 mm等名义尺寸沿用本地 FPM583F 手册。

硅胶沿用 BISCO HT-6240、40 Shore A、0.020 英寸（0.508 mm）名义厚：

- 指纹环一片，外径 20.5、内径 18.8 mm。
- 尾垫两片，各 1.2 × 1.2 mm。
- 上垫一片，0.8 × 12 mm，跨过左右托架的中央小接缝。

净间隙名义 0.42 mm；片材厚度公差、去除载体、鼓胀空间及不增加胶层的要求沿用 [V6 材料记录](concept-v6.md#指纹固定与硅胶规格)。
须量实际垫厚及装配间隙，不把厚度压缩比例当作夹紧力或长期回复性能证明。

金属件仍为两颗 M2 × 10、圆柱头内六角螺丝，配 M2、外径 3.6、长 4 mm 热熔嵌件。
螺丝头径上限 3.8、高上限 2 mm；不得换更长螺丝。
上盖底孔直径 3.2、深 5 mm，柱径 6.4；嵌件入口 Z = 9.5 mm，嵌件不得向下突出。
金属与电路之间仍以连续塑料及 1.2 mm 预留包络检查，不新增接触电气焊孔的金属固定件。

## 装配与验收

1. 商家试孔、修配定位柱/孔并安装嵌件，清除加工和金属残屑。
2. 断电，将三片 PCB 硅胶垫放入左右托架槽；用临时托持保持位置，再从左右两侧水平套住板件的前后裸边。
3. 板件与两半托架作为一组竖直落入底壳，安装耳套住绝缘定位柱并贴合肩面；取走临时托持。
4. 指纹模块放入一体托环，装入环形硅胶垫，整理线束。
5. 上盖连同 U 形前壁竖直放下，槽口绕过 USB，底壳中央前壁补齐孔下沿；两道上方筋停在板面以上。不得强压有干涉的前壁或托架。
6. 交替轻拧两颗 M2 × 10，确认安装耳受夹持，PCB 和模块无明显窜动、摇摆或硬压。
7. 断电检查所有焊点、针脚、金属件和线束隔离，尤其检查加宽的前下托片及上盖前端筋。
8. 测全部前部表面的实际 USB 阻挡 ≤ 1 mm，再试插到底，检查 BOOT、RUN、LED 及指纹操作空间。
9. 测实际接口拔出力，确定验收载荷；在独立夹具上检查壳体拉动时的变形、裂纹和板件位移，再做反复插拔。不得用电脑端口作破坏试验夹具。

本版仅用于一套试装。软件检查不等于抗拔强度或寿命验收，未验收前不直接批量加工。

## 复现与检查范围

沿用已校验官方参考文件，`OPENSCAD` 指向 OpenSCAD 2021.01 或兼容版本：

```sh
nix develop -c python enclosure-design/verify_trial.py --openscad "$OPENSCAD"
nix develop -c python enclosure-design/trial_preview.py
HOST_TARGET=x86_64-unknown-linux-gnu nix develop -c ./scripts/check.sh > enclosure-design/build/v9-project-check.log 2>&1
nix develop -c python enclosure-design/package_trial.py
```

结果以 `build/v9-geometry-checks.json` 及 `build/v9-project-check.log` 为准。
检查四个独立闭合实体、六组配合、官方器件及名义 PCB、14 mm 叠层占位、USB、硅胶、金属隔离和线束通道。
九处根部各检查补料点有实体、圆弧外侧为空，并将对应圆角半径置零验证缺失对照；同时拒绝侵占 USB 或 PCB 净空的过大半径。
另将两组筋与冻结的 V7 剖面作实体差集，要求原筋芯没有任何缺失；外侧筋基准平移到 V8/V9 的横向位置后比较。
恢复 V8 两组筋根高度的对照必须产生缺失体积；检查的是完整筋芯包含关系，不能由总材料体积增加代替。
同一检查入口已在保留 V8 抬高筋根时失败，用于验证该项确实能拦住截面退步。
导出网格须位于 51.8 × 27.2 × 19 mm 的外形包络内；外形检查已用未裁齐螺柱圆角产生的 27.6 mm 宽度反例验证拒绝。
检查整组下落及上盖合入的连续扫掠，以及左右托架侧向套入的七个位置；离散位置不证明全部连续侧向运动。
保留错移器件/金属、托架抬高及缺失加强筋的对照。零厚度接触面以相交体积小于 10⁻⁶ mm³ 判定，不要求仅有一个接触面。
全叠层占位明确豁免前后承托及前端上方筋，再由不带豁免的官方器件/PCB 检查核对。

官方 STEP 缺少 USB、Flash、手工叠层板、排针、配对插头和电线，不能据此证明实物全覆盖。
官方板框与名义外形约差 0.014 mm，不能由参考网格反推实物加工公差。
当前未验证材料变形、螺丝预紧力、完整公差链、破坏载荷、反复拆装及长期蠕变。
