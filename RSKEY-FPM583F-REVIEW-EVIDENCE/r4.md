## 故障控制

源文件：[r4_controls.py](r4_controls.py)。固定 Nix 环境下运行：

```sh
NIX_CONFIG='experimental-features = nix-command flakes' \
  nix develop --offline --no-update-lock-file -c \
  python RSKEY-FPM583F-REVIEW-EVIDENCE/r4_controls.py
```

脚本从当前 `check.sh` 提取候选配置、真实 `run` 包装和目标行，在仓库外的临时
源码副本执行；只替换副本中的源码或候选参数。客户端控制通过
`PYTEST_ADDOPTS` 收集临时失败断言并筛掉正式用例，执行 CI 的原始命令。
